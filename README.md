# English Practice

Веб-приложение для тренировки разговорного английского и подготовки к собеседованию в посольстве США.

Работает полностью статически — можно открыть через **GitHub Pages**.

## Возможности

- **~210 слов** с переводом и примерами (повседневное, виза/интервью, работа, семья, образование, путешествия, чувства, время)
- **Карточки** (flashcards) с переворотом, пометкой «Знаю» / «Ещё раз»
- **Тесты**:
  - EN → RU (выбор перевода)
  - RU → EN (выбор английского слова)
  - Напиши слово (ввод с клавиатуры)
  - Предложения (заполни пропуск)
- **Прогресс**: изученные слова, серия дней, количество пройденных тестов (хранится в localStorage)
- **Тёмная и светлая тема**
- Приятный минималистичный дизайн, без лишней анимации

## Как открыть

1. В репозитории: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Сохрани — через минуту сайт будет доступен по адресу:
   `https://smert-s-games.github.io/english/`

Или просто открой `index.html` локально в браузере.

## Структура

```
index.html      — разметка
styles.css      — стили + темы
app.js          — логика
data/words.js   — база слов и предложения для тестов
```

Дальше можно вместе пополнять базу слов, добавлять новые типы упражнений и темы под интервью.
